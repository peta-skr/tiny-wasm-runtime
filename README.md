# tiny-wasm-runtime

ゴリラ（skanehira）著『RustでWasm Runtimeを実装する』（Zenn Book）に沿って、RustでWebAssemblyのランタイムを実装しているリポジトリ。本の第10章「Runtimeの実装 〜関数の呼び出しまで〜」の途中、エクスポートした関数を名前で呼び出して実行するところまで進めている。

## できること

- Wasmバイナリのデコード。マジックナンバー `\0asm` とバージョンを確かめ、Type・Function・Code・Exportの4つのセクションを読む
- 値の型は `i32` と `i64`、命令は `local.get`・`i32.add`・`end` の3つに対応する
- 関数のローカル変数宣言（`(local i32)`、`(local i64 i64)` など）のデコード
- デコードしたモジュールから、関数インスタンスとエクスポートの表を持つStoreを組み立てる
- エクスポート名を指定して関数を呼び出し、スタックマシンで実行して戻り値を返す（例: `add(2, 3)` が `5` を返す）
- 存在しないエクスポート名を指定したときはエラーを返す

Import・Memory・Dataセクションは種別の定義だけがあり、デコードはまだ実装していない（`todo!()`）。関数から関数を呼ぶ `call` 命令も未実装。

## 動かし方

`Cargo.toml` の edition は2021。初回は依存クレートのダウンロードが必要。

```
cargo test
```

テストは `src/binary/module.rs`（デコード5件）と `src/execution/runtime.rs`（実行2件）にある。テストの中で `wat` クレートを使ってテキスト形式（WAT）をWasmバイナリに変換し、それをデコード・実行して結果を比べる。WATのファイルは `src/fixtures/` に置いている。`src/main.rs` は `cargo new` の雛形のままで、現状はライブラリとしてテストから動かす。

## 構成

```
src/
├── lib.rs
├── binary.rs / binary/      Wasmバイナリのデコード
│   ├── module.rs            Module構造体と各セクションのデコード（テストもここ）
│   ├── section.rs           セクションID、関数本体（ローカル宣言＋命令列）
│   ├── types.rs             関数型、値の型、エクスポート
│   ├── opcode.rs            オペコードとバイト値の対応
│   └── instruction.rs       デコード後の命令
├── execution.rs / execution/  実行
│   ├── store.rs             Moduleから関数インスタンスとエクスポート表を作る
│   ├── runtime.rs           フレーム、コールスタック、命令の実行（テストもここ）
│   └── value.rs             実行時の値（I32 / I64）と加算
└── fixtures/                テスト用のWAT
```

## 設計・実装のポイント

いずれも本の構成に沿っている。

- デコードはパーサーコンビネーターの `nom` で書き、可変長整数（LEB128）は `nom-leb128` で読む。セクションは「ID（1バイト）＋サイズ（LEB128）」のヘッダを先に読み、サイズ分だけ切り出してセクションごとの関数に渡す
- バイト値から列挙型への変換は `num-derive` の `FromPrimitive` で行う（`SectionCode`、`Opcode`）
- デコード（`binary`）と実行（`execution`）を分けている。実行側では、Functionセクションの型インデックスとCodeセクションの関数本体を組にして関数インスタンスを作り、ローカル宣言の「個数×型」を1つずつに展開しておく
- 関数を呼ぶと、引数をスタックからローカル変数へ移し、フレーム（プログラムカウンタ、スタックポインタ、命令列、戻り値の数、ローカル変数）をコールスタックに積む。`end` でフレームを外すときは、戻り値の数に応じて値を1つ残し、スタックを呼び出し時の位置まで巻き戻す（`stack_unwind`）
- 実行中にエラーが起きたら、スタックとコールスタックを空にしてからエラーを返す
- テストではデコード結果を `Module` 構造体ごと `assert_eq!` で比べ、差分は `pretty_assertions` で表示する

## 学んだこと

- Wasmバイナリの構造。セクションヘッダ、LEB128による可変長整数、型・関数・コード・エクスポートの各セクションがインデックスでつながる関係
- `nom` のパーサーコンビネーターでバイナリ形式を読む書き方
- スタックマシンでの関数呼び出し。フレームとスタックポインタを使って、戻り値だけを残してスタックを巻き戻す手順
